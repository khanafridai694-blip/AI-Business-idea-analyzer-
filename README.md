# 🚀 AgentForge

AgentForge is a multi-agent AI application that analyzes startup,
product, app, SaaS, and business ideas.

The system uses specialized AI agents to analyze an idea from
different perspectives, challenge the initial analysis, and produce
an improved startup plan.

## Features

- Market analysis
- Business analysis
- Technical feasibility analysis
- AI Challenger
- AI Debate
- Improved startup plan
- 90-day roadmap
- Elevator pitch

## Technology

- Python 3.12
- Streamlit
- CrewAI
- Groq
- GPT-OSS 120B
